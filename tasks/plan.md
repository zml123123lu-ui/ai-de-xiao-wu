# 爱的小屋实施规格

## 目标

为固定的两位成员提供一个公网部署、登录后私密使用的交流空间，包含问题讨论、正式书信和每日状态。

## 技术栈与命令

- Next.js App Router、TypeScript、Supabase Auth/PostgreSQL、Vercel
- 开发：`pnpm dev`
- 检查：`pnpm lint && pnpm typecheck && pnpm test`
- 构建：`pnpm build`
- 浏览器测试：`pnpm test:e2e`

## 边界

- 始终：服务端校验写操作；数据库启用 RLS；正文仅以纯文本渲染；不提交密钥。
- 需另行决定：增加成员、附件、公开内容、邮件通知或新的身份验证方式。
- 禁止：开放注册、使用前端隐藏代替授权、允许修改已寄出的信件。

## 成功标准

两位固定账号可跨设备登录并完成问题回复、信件草稿/寄出/已读和每日状态同步；匿名或第三个账号无法读取数据；移动和桌面布局可用。
