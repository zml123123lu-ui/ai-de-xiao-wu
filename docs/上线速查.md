### 以后怎么更新线上

```bash
cd "/Users/lu/Documents/ChatGPT/我和小九的交流台"
NETLIFY_AUTH_TOKEN=<你的令牌> bash dev/deploy-netlify-cli.sh
```

它会本地构建（Netlify 的 Next.js 运行时把产物打包成 Functions）再直传，约 2 分钟。

> 为什么不用"Git 推送后自动部署"：Netlify 的 Git 集成需要先授权它的 GitHub App，
> 没有授权时构建会在 `preparing repo` 阶段失败（`Host key verification failed`）。
> 想做自动部署的话，在 Netlify 项目里点一次 **Link repository** 授权即可，
> 之后 `dev/sync-to-github.sh` 推代码就会触发构建。

### 一个容易再踩的坑

Netlify 账号级的 **SSO 访问保护**默认是开的，新建站点会继承，于是整站返回 401
（一个 "Login Redirect" 页面）。关掉站点级的即可：

```bash
curl -X PATCH -H "Authorization: Bearer $NETLIFY_AUTH_TOKEN" -H "Content-Type: application/json" \
  -d '{"sso_login":false}' https://api.netlify.com/api/v1/sites/<站点ID>
```


目标：不买域名、不备案，让你们在国内不靠梯子也能打开。原理见 [deploy-cn.md](deploy-cn.md)「路线 Z」：
应用跑在免费托管上，**自己转发** Supabase（免费数据库域名在国内全部不通，托管域名可以）。

## 你要做的五步

- [x] **1. 推代码到 GitHub** —— 已完成：https://github.com/zml123123lu-ui/ai-de-xiao-wu （私有）

  > `gh auth refresh -h github.com -s workflow` 然后 `bash dev/sync-to-github.sh --with-workflows`

  若创建时报错说不支持 `singapore` 区域，删掉 `render.yaml` 里 `region: singapore` 那一行，

## 会碰到什么

- 闲置 15 分钟后休眠，**再打开约 1 分钟**——这期间 Render 会显示它自己的加载页，不是白屏。
- 用不着保活也能用；想要"随时秒开"就把 `.github/workflows/keep-alive.yml` 留着
  （它只在北京时间 07:00–24:00 每 10 分钟 ping 一次，约 540 小时/月，免费额度 750）。
- 每月 750 小时是整个工作区共享，**超了会把该工作区所有免费服务停到月底**，所以别再开第二个。

## 出问题先看这里

| 现象 | 多半是 |
| --- | --- |
| 一直跳回登录页 | `SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_URL` 与真实域名不一致 |
